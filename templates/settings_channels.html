Where do I get these keys?

  • Email (Brevo): brevo.com → SMTP & API → SMTP key. Free: 300 emails/day. Use your own verified sending domain for best deliverability.
  • Telegram: talk to @BotFather on Telegram → /newbot → copy the token. Free. You can only message users who sent /start to your bot first.
  • Twilio SMS: console.twilio.com → Account Info → SID + Auth token, and buy a number. Malaysia ~RM0.04–0.10 per message.
  • RedSMS: redsms.com (Malaysian gateway) — verify the API format against the docs you receive with your account.
  • WhatsApp (Meta Cloud): developers.facebook.com → create app → WhatsApp product → get Access Token + Phone Number ID. Requires Meta Business verification for production. Reply-only by design: free-form messages only work within 24h of the user messaging you.
  • X (Twitter): developer.x.com → developer portal → API keys. Pay-per-use. Publish/monitor only — no cold DMs on any affordable tier.
